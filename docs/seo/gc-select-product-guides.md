# GCセレクトへつなぐ商品比較記事

調査・公開日：2026-11-22

## 今回の対象

購入する商品を選ぶ読者に、写真・用途・寸法・販売単位を示し、GCセレクトの商品詳細へ案内する。工事・イベント全体の計画が必要な読者は、既存のGC安全向け相談記事へつなぐ。

検索ボリューム、キーワード難易度、Search Console実績は未取得。検索結果の構成と公式商品の情報を確認したうえでの選定であり、上位表示・流入数の保証や数値の推定は行わない。

## 検索意図と記事の分担

- `cone-sign-installation-guide`：主軸は「コーン 看板 取り付け」。関連語は「コーンサイン キャップ 別売」「コーンカバー サイズ 立入禁止」「コーンサイン 両面」。コーン本体の種類・サイズを扱う既存記事から分け、表示用品と取付部品の買い物に集中する。
- `office-emergency-blanket-selection`：主軸は「会社 備蓄 毛布 圧縮」。関連語は「備蓄 毛布 収納 サイズ」「圧縮毛布 アルミシート 違い」「備蓄毛布 10枚」。既存の企業向け備蓄品一覧・数量全般の記事から分け、寝具と携帯する防寒用品の選定を扱う。

「安全用品」「防災用品」「毛布」のような広い単語だけを狙わず、購入直前に確認したくなる部品・収納・注文単位をタイトル、本文、比較表、FAQへ自然に織り込む。季節のキャンペーンや価格の安さ、実証していない人気順を訴求の根拠にしない。

## 検索結果で確認したこと

2026-11-22に「コーン 看板 取り付け キャップ」「コーン 看板 差し替え A4 取り付け」「圧縮毛布 アルミシート 違い 備蓄」等を検索。

- コーン関連は専門通販の商品ページ、メーカーの取付資料、MonotaROのカテゴリ・商品ページが表示された。専門通販も含まれることを確認したが、競争が弱いとは断定しない。表示板・取付部品・適合寸法・両面の必要数を一度に整理することで、商品単体ページとは異なる判断材料を提供する。
- A4差し替え式も候補として調査したが、今回紹介するGCコーンサインを用紙差し替え式と誤認させないため、主題に採用していない。FAQで既製表示板との違いのみ説明。
- 毛布関連は防災事業者の解説、メーカー資料、比較記事が表示された。アルミシートとの使い分けに加え、実商品の収納寸法・販売単位・注文計算を結び付ける切り口を選定。
- ヘルメット防寒インナーや融雪用品も商品候補を調査したが、今回は既存記事との分担と公式仕様の確認が十分にできる2本を採用した。

## 導線・SEO・計測

- 1200pxの既存記事幅を継承。PCは大きな写真の2列、スマートフォンは1列。ヒーローの商品写真、用途別の本文内ジャンプ、商品別CTA、カテゴリCTA、記事専用の追従バーを設置。
- 商品リンクは通常のa要素で、JavaScriptなしでも遷移可能。価格・在庫・出荷日の固定表示はしない。
- UTMは `utm_source=sagyou_navi`、`utm_medium=referral`、`utm_campaign=記事slug`、`utm_content=設置場所`。
- 本番でのみVercel Analyticsの `ec_guide_shop_click` を送信。項目は `article`、`placement`、`product`。クリックは購入完了とは区別する。
- 既存の記事データへ登録し、トップ・記事一覧・サイトマップに反映。既存のコーン種類、企業備蓄、臨時駐車場、安全保安用品のまとめから4本のリンクを追加。
- 固有のtitle・description・canonical・OG画像、ArticleとBreadcrumbListの構造化データ。自社で販売価格や在庫を維持しない比較記事なので、架空のOffer・レビュー・評価・Product構造化データは追加しない。
- 今後データが取得できる場合、検索クエリ別の表示回数とCTR、記事内の商品クリック、EC側のUTM付き流入と購入を別々に確認する。定期実行は設定しない。

## 検証記録

型チェック・変更対象のESLintを通過。2記事のHTML、canonical、Article/BreadcrumbList、目次、画像、サイトマップ、内部リンク、UTMを確認した。商品別の遷移先はコーン5点、備蓄4点。ブラウザでは320/390/768/1280pxで表示を確認し、FAQの開閉・商品比較へのジャンプ・GCセレクトの商品詳細への実際の遷移を検証した。320pxでFAQを開いた際の記号の回転による横はみ出しを修正し、再確認済み。
